RetroArch 1.22.2，附带自由的 libretro 核心，为 R36S 等 Gizlet 掌机打包。

| 主机 | 核心 |
| --- | --- |
| NES / FC | Nestopia |
| SNES / 超任 | bsnes-mercury（性能版） |
| Game Boy、Game Boy Color | Gambatte、mGBA |
| Game Boy Advance | mGBA |
| PC Engine | Beetle PCE Fast |
| WonderSwan | Beetle WonderSwan |

本软件包不含任何游戏、BIOS 文件或游戏美术。在 RetroArch 菜单的 **Load Content** 中打开你自己拥有的游戏；插入 TF2 卡时会从 TF2 卡开始浏览，或从模拟器中心选择的文件夹开始。若核心需要 BIOS，请把你自己的文件复制到存档数据中 RetroArch 的 `system` 文件夹。

RetroArch 的联网功能已关闭。存档、即时存档和设置保存在应用自己的存档文件夹中，你的存储卡只会被读取。

**按键。** 按住 Select 使用热键：Select + X 打开菜单，Select + Start 退出（按两次），Select + L 读取、Select + R 保存即时存档，Select + R2 快进。按住 FN，或同时按住 Select 和 Start 两秒，返回 Gizlet 启动器。
