RetroArch 1.22.2 with free libretro cores, packaged for Gizlet handhelds such as the R36S.

| System | Core |
| --- | --- |
| NES / Famicom | Nestopia |
| Super NES | bsnes-mercury (performance) |
| Game Boy, Game Boy Color | Gambatte, mGBA |
| Game Boy Advance | mGBA |
| PC Engine / TurboGrafx-16 | Beetle PCE Fast |
| WonderSwan | Beetle WonderSwan |

The package contains no games, BIOS files or game artwork. Open the games you already own with **Load Content** in RetroArch's menu; it starts on your TF2 card when one is mounted, or in the folder Emulation Center chose. If a core needs a BIOS file, copy your own into RetroArch's `system` folder in its save data.

RetroArch runs with its online features turned off. Saves, save states and settings stay in the app's own save folder, so your card is only read.

**Controls.** Hold Select for hotkeys: Select + X opens the menu, Select + Start quits (press twice), Select + L loads and Select + R saves a state, Select + R2 fast-forwards. Holding FN, or Select and Start for two seconds, returns to the Gizlet launcher.
